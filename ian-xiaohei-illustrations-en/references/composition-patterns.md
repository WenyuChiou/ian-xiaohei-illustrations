# Composition patterns & originality rules

## Base structure types

Pick one; don't mix too many.

### Workflow

For: input → process → output, content production, AI workflows, automation chains.
Draw: input on the left, Xiaohei or a strange machine processing in the middle, output on the right, orange arrows for the main flow.

### System fragment

For: information sources, filters, databases, renderers, a slice of an agent system.
Draw: only 3–5 core modules; Xiaohei participates in one key action.

### Before / after

For: chaos vs order, manual vs automatic, scattered vs converged, anxious vs calm.
Draw: chaos on the left, calm on the right, an orange arrow between. The character can be more exaggerated.

### Role state

For: user pain, creator state, too many tools, info anxiety, stuck → running.
Draw: 2–4 small states, one short label each.

### Concept metaphor

For: content factory, info warehouse, mental black box, workflow machine, automated daily report.
Draw: one big strange object or machine, a few inputs, one output. Make it memorable.

### Layered method

For: methodology frameworks, system layers, capability stacks, content-system tiers.
Draw: stacked boxes (not a formal pyramid); Xiaohei building or hauling beside them.

### Map / route

For: idea → launch, user journey, content handoff path, learning path.
Draw: one winding path, a few nodes, Xiaohei pulling a line or walking.

### Mini comic

For: failure → success, the real process, a gripe, before/after using something.
Draw: 2–4 small panels, one action per panel.

## How to invent an original metaphor

Reinvent the metaphor from the current text every time; never reuse an old image.

1. Turn the abstract concept into a physical action: stuck, leaking, getting heavier, sorting, settling, fermenting, opening, folding, unpacking, flowing back.
2. Turn the system structure into a low-tech object: a broken machine, a cardboard box, a drawer, a pipe, a mailbox, a strange dial, a scale, a well, a ladder, an odd workstation.
3. Let Xiaohei carry the action: not standing beside it, but stuck in the machine, pulling the wrong line, guarding a gate, hauling, patching, weighing, holding a ladder, recording, or shoving something into a strange device.

### Object pool

Cardboard box, drawer, old machine, funnel, scale, mailbox, door, well, ladder, pipe, ball of string, gate, turntable, black box, hole-punch, pasta press, clothesline, odd workstation. Use only 1–2; don't pile them up.

### Xiaohei action pool

Pull, haul, shove, scoop, press, weigh, stitch, cut, twist, guard, push, catch, unpack, mark, recycle. The action must serve the core meaning; don't be strange just to be strange.

## Anti-copy rule

Don't open or copy `assets/examples/` by default. They calibrate style only (line density, whitespace, color restraint, Xiaohei's vibe).

Unless the user explicitly says "use this one / copy this composition", don't reuse known compositions. For the same topic, still invent a new metaphor — for a "handoff path", you don't have to draw a route; you could draw Xiaohei hooking the tail of one piece of content onto a doorknob.
