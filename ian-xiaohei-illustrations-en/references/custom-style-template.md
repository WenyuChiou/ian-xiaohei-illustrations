# Custom style profile (template)

Copy this to `references/custom-style.md` to change the *look* (palette / line / background) without touching the structure rules. The default profile is `references/style-dna.md` — start from it and override only what you need.

- **Background:** {default: pure white. e.g. very light warm paper, soft grey — keep it calm and low-texture}
- **Line:** {default: thin black hand-drawn, slightly wobbly. e.g. slightly thicker, or dark navy instead of pure black}
- **Primary color (structure / character):** {default: black}
- **Accent colors:** {default: red = key points / problems, orange = main flow / arrows, blue = secondary notes. Re-map if you want, but keep to ~3 restrained accents}
- **Whitespace:** {default: subject 40–60%, at least 35% blank. Keep generous whitespace — it is core to the look; do NOT reduce below 35% blank — that is spine, not surface}
- **Forbiddens:** {default: no gradients, shadows, paper texture, PPT / infographic look, glossy / 3D, cute cartoon. Keep these unless you have a strong reason}

## What a style profile must NOT change

These are not style — they are the skill's spine, and they hold for every profile:

- One image = one core idea / structure.
- The active IP character performs the core action (never decoration).
- Generous whitespace; clean, deadpan, absurd-but-coherent; not a manual, not a PPT.

A style profile swaps the *surface* (colors, line, background). If you find yourself changing the spine, you want a different skill, not a new profile.
