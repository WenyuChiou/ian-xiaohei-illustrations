# 自定义风格模板

将此文件复制到 `references/custom-style.md` 以更改*外观*（调色板/线条/背景），而不影响结构规则。默认配置文件是 `references/style-dna.md`——从它开始，只覆盖你需要的部分。

- **背景：** {默认：纯白。例如：非常浅的暖色纸、柔和的灰色——保持冷静和低纹理}
- **线条：** {默认：细的黑色手绘线条，略带抖动。例如：稍粗一些，或用深海军蓝代替纯黑}
- **主色（结构/角色）：** {默认：黑色}
- **强调色：** {默认：红色=关键点/问题，橙色=主流向/箭头，蓝色=次要注释。如果你想，可以重新映射，但保持在约3种克制的强调色}
- **留白：** {默认：主体占40-60%，至少35%空白。保持宽裕的留白——这是外观的核心；**不要**减少到35%以下——这是龙骨，不是表皮}
- **禁忌：** {默认：无渐变、阴影、纸张纹理、PPT/信息图外观、光滑/3D、可爱卡通。除非有充分理由，否则保留这些}

## 风格配置文件不能更改的内容

这些不是风格——它们是技能的龙骨，适用于每个配置文件：

- 一图一意：一个图像=一个核心思想/结构。
- 当前 IP 角色承担核心动作（绝不只是装饰）。
- 宽裕的留白；干净、冷面、荒诞但连贯；不是说明书，不是 PPT。

风格配置文件更换的是*表皮*（颜色、线条、背景）。如果你发现自己在改变龙骨，那么你需要的是一个不同的技能，而不是一个新的配置文件。
