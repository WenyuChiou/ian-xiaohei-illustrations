# 自定义 IP 角色模板

将此文件复制到 `references/custom-ip.md` 并填写，用你自己的角色替换小黑。内容要简短——这是给生图工具看的描述，不是正式规格书。

- **名字：** {你的角色名}
- **轮廓/身体：** {一个实心、简单的形状——一团、一颗豆子、一个盒子、一个圆角图标。简单的形状在小尺寸下可读性最好。}
- **眼睛：** {例如：两个白点 / 一只眼睛 / 一条细长的护目镜}
- **四肢：** {细腿？细胳膊？没有？}
- **脸/表情：** {面无表情？空白？一个固定的表情——避免复杂情绪}
- **感觉：** {认真的工人 / 笨拙的操作员 / 冷静的机器——不要是可爱的吉祥物，也不要是精致的品牌标志}
- **擅长的动词：** {拉、扛、堆、守、倒、缝...——它在场景中承担的工作}
- **禁忌：** {永远不要画的东西——复杂的衣服、闪亮的眼睛、身上的文字、光滑的 3D 标志外观等}
- **Seed (可选):** {一个固定的整数，用于在多张图中保持角色的一致性}

## 不可协商的规则

`performs_core_action: true`

你的角色**必须**是执行每个图像核心动作的那一个。如果去掉它，隐喻仍然完全成立，那它就是装饰——重写，让角色来做这项工作。只站在角落里的角色会让这个技能变成一个通用的插画提示词，完全违背了它的初衷。

## 从样本图像生成（自带图标）

如果你的吉祥物或图标有图片，把它交给助手。它会：

1.  查看图像，并用**文字**在此文件中描述轮廓/眼睛/四肢/感觉（文生图工具是从这些文字描述中渲染，而不是从图像本身）。
2.  在生成前与你确认描述。
3.  锁定一个固定的 `seed`，以便角色在整篇文章的图像中保持一致。

保持角色简单和高对比度——一个单一的实心轮廓在这种手绘、稀疏的风格中，比一个细节丰富、多色的标志生存得更好。
